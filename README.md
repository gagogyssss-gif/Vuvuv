# Vuvuv Username Lab

Android-приложение для локального подбора и сортировки username-кандидатов.

Что есть в текущей версии:
- 20 000 общих кандидатов: 17 000 английских слов + 3 000 modern-компаундов вроде `OmniHash`, `NeonVault`, `MetaDrugs`;
- отдельный пул на 4 000 никнейм-стилей для режима ShuzoGram;
- отдельный translit-пул;
- несколько фильтров можно включать одновременно;
- режим «ровно 5 букв» и «5+ букв»;
- тёмный liquid-glass интерфейс;
- статусы «занят» и «свободен» сохраняются локально;
- занятые варианты больше не предлагаются;
- копирование текущего кандидата в буфер обмена.

В этой версии нет автоматического управления Telegram, массового перебора username через интерфейс другого приложения и автоматического создания каналов. Проверку доступности пользователь выполняет сам и затем отмечает результат в приложении.

## Сборка

GitHub Actions workflow `Build Username Lab APK` собирает debug APK.

Локально:

```bash
gradle :app:assembleDebug
```

Готовый APK после сборки:
`app/build/outputs/apk/debug/app-debug.apk`

## Word corpus

Для частотной английской лексики использован и отфильтрован публичный список из проекта:
`david47k/top-english-wordlists`.
