# FrameCut

Android-приложение для создания чистых коротких клипов из видео без записи интерфейса приложения.

## Что уже сделано

- открытие локального видео, прямых MP4/HLS/DASH ссылок и обычных веб-страниц во встроенном WebView;
- обнаружение обычных HTML5-медиапотоков на странице;
- режим «Начать → Стоп»: приложение запоминает таймкоды и затем экспортирует исходные кадры, поэтому кнопки, жесты и рамка кадрирования не попадают в итоговое видео;
- точный диапазон по таймкодам (`32:30` → `33:10`);
- AutoCrop под 9:16 Shorts;
- ручная двигаемая рамка с регулируемой чувствительностью и зумом;
- 9:16, 1:1 и 16:9;
- 720p / 1080p / 1440p / 4K;
- максимум 24 / 30 / 60 fps;
- H.264 и H.265/HEVC;
- сохранение звука в AAC;
- сохранение MP4 в `Movies/FrameCut` и системный Share Sheet;
- тёмный glassmorphism UI со свечением и плавными состояниями;
- отдельное меню настроек.
